              Shipper formats

              Each shipper's documents are read using what was confirmed the first time. If a shipper changes their layout, the app asks again and updates the format when you save. To share what this PC has learnt, Export and send the file to colleagues; they Import it on their PC.

              Shipper names (one name per shipper – admin)

              Different spellings, invoice-number starts and GSTINs of one shipper are saved under one name, so the same invoice is never added twice under two spellings. The list goes with Export formats / Import formats file to the other PCs.

              Combine from shared folder (automatic)

              Each PC keeps its data file in one shared folder (OneDrive, SharePoint or a network drive) – set it up once on each PC in Import / backup → Create data file. Choose that folder here once; after that one click reads every PC's latest data and makes the combined reports, one per CFS.

              Combine stock reports (Excel files)

              Each PC keeps its own stock. Ask colleagues for their latest stock report (Stock tab → Download stock report), then choose those files here. The result is one report with an ALL sheet and one sheet per customer. Rows that appear in more than one report (same invoice + PO + style) are kept once and listed on a "Duplicates removed" sheet.

              Import the current stock report

              Load your existing Excel stock report (the one with the ALL sheet) so the app starts with today's stock. Rows are added as they are; check the Stock tab afterwards.

              Data file (recommended)

              The app keeps your stock and shipper formats inside this browser. To be safe if browser data is ever cleared, link a data file (for example in OneDrive or a shared drive): it is updated automatically after every change.

              This browser cannot link a data file. Use Microsoft Edge or Google Chrome, or use Download backup below regularly.

              Drop-down lists (stuffing)

              Kept by the admin: one entry per line. Operators pick from these lists on the stuffing screen. Saving needs the admin PIN.

              Excel upload: one column per list, the list name in the first row (e.g. Carrier, Unit, Vessel, Transporter …).

              Admin PIN

              Editing or deleting stock that has been added needs the admin PIN (set separately on each PC). Operators can still read documents, add stock, mark shipped out and download reports.

              Shipper & CHA list

              The CHA Name is filled automatically for each shipper: from this list first, otherwise from the shipper's last shipment. It can always be changed on the reading screen.

              The file needs two columns: Shipper and CHA Name (header in the first rows). Tip: download the current list, complete it in Excel, upload it again.

              Report headers

              The surveyor lines printed at the top of each site's stock report. Chennai sites (HTPL, SATTVA) use PINNACLE, Tuticorin sites (ST JOHN, SICAL) use EVERBLUE.

              Backup

              Download a copy of everything (stock and shipper formats) as one file. Keep it on a shared drive or pen drive.
